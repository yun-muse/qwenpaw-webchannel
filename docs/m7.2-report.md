# M7.2 report — relay connection self-healing + plugin file log

Root cause and evidence: `docs/m7.2-findings.md`. Scope per the milestone
mandate: make the plugin's relay connection recover from a dead tunnel on its
own, make the failure observable from inside (plugin file log) and outside
(relay `/health`), and prove it with kill-and-recover tests. Local work only —
the hosted reinstall and soak are the follow-up step.

## Changes

- `plugin/relay_client.py` — connection lifecycle reworked:
  - Per-connection phase runs reader/writer/heartbeat under
    `asyncio.wait(FIRST_COMPLETED)`; the first task to end ends the phase,
    the rest are cancelled with a bounded cleanup. A parked frame callback
    can no longer freeze the connection.
  - `_supervise()` wraps the run loop: any non-fatal exit (including
    `BaseException`) restarts it; explicit stop and close 4000 stay final.
    M7.1 test semantics preserved (on 4000 the client task finishes).
  - `websockets.connect` gets `ping_interval=20` / `ping_timeout=20` (was
    `None`): transport-level dead-tunnel detection.
  - All sends bounded by `send_timeout=10 s` (`asyncio.wait_for` under the
    existing `_tx_lock`).
  - Senders record the close code too (`_note_close_code`): a 4000 first
    noticed by the writer/heartbeat is still fatal.
  - Lifecycle events written to the optional `file_log` (connect, hello,
    phase_end, close, reconnect, loop_exit, supervisor_restart, fatal,
    stopped); no behaviour change when no file log is configured.
- `plugin/filelog.py` (new) — `FileLog`: append-only line log,
  `YYYY-MM-DD HH:MM:SS.mmm event k=v`, rotates at 256 KB keeping two
  backups, `write()` never raises.
- `plugin/channel.py` — `WebChannel.start()` opens
  `<workspace>/webchannel.log` (fallback: plugin dir; any failure → no file
  log) and passes it to `RelayClient`; writes `channel_start` /
  `channel_stop`.
- `relay-cf/src/index.ts` — the DO tracks the agent socket's last business
  frame time (hello + forwarded frames; the auto-answered app-level ping
  does not count) and `GET /health` returns it as `agentLastSeen` (ms epoch
  or `null`). relay-node intentionally unchanged (dev mirror; semantics
  noted in the findings).
- `AGENTS.md` — the self-healing invariant recorded as a project convention.
- Tests: `plugin/tests/test_m72.py` (scenarios A destroy, B silence,
  C parked callback, D supervisor restart on `BaseException`, E file-log
  events, F FileLog rotation/never-raise, G writer-first 4000);
  `tests/repro_m72.py` (before/after harness, `--client-dir`);
  `tests/e2e_m72.mjs` (owns relay-node, 3 SIGKILL/respawn cycles with
  single-shot probes); `tests/e2e_cf.mjs` gained the AGENT-LAST-SEEN
  assertion group.
