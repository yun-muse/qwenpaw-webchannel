## Root cause (one paragraph)

A model switch makes QwenPaw hot-reload the agent workspace
zero-downtime: the NEW workspace's RelayClient connects and the relay
evicts the OLD socket (close 4000), but the old workspace's `stop()`
only runs afterwards — seconds later on the hosted container, and on
the app's delayed-cleanup path potentially far later. The old
RelayClient treated the 4000 eviction as a transient drop and
reconnected after its 1 s backoff, evicting the new instance in turn:
a ~1 Hz replacement war over the relay's single agent slot, ending
with frames routed to a dead workspace (chat) or, on the CF relay
after a hibernation rebuild, to a stale socket — while `/health`
kept reporting the agent online. Reproduced locally with an
instrumented relay + a 6 s artificial stop delay: 42 agent
connections across 6 switches, war stopping only when `stop()` ran.

## The fix (generation-gated agent slot; protocol/frames.md §3)

- **plugin/relay_client.py**: `hello` now carries `session` (uuid)
  and `started` (construction time, wall-clock µs). The reader
  records the close code; **close 4000 = superseded → `_fatal`, never
  reconnect**. Transient closes keep the existing backoff reconnect.
- **relay-node/server.js** and **relay-cf/src/index.ts** (lockstep):
  agent sockets are parked at upgrade (no more upgrade-time
  eviction); the slot is won at `hello` — an older `started` is
  closed 4000 ("superseded") without disturbing the holder, a
  newer/equal hello takes the slot (`peer` + outbox flush + `ready`).
  Frames from non-holder agent sockets are never forwarded. Legacy
  hellos without `started` count as generation 0.
- **relay-cf**: the winner's `{won, started, session}` lives in the
  socket attachment; the hibernation rebuild picks the
  greatest-`started` winner and restores its generation, instead of
  "last socket wins".
- **SPA: unchanged** — the silence was never client-side (raw
  protocol probes went equally unanswered); no watchdog needed once
  the slot is stable.
- Docs/mock/tests: `protocol/frames.md` documents the generation
  rule; `mock/mock_agent.mjs` hello carries the new fields;
  AGENTS.md records the invariant.
