# M40 — 收尾包：测试制品政策 + 模型选择器 e2e + 协议文档补全

M38 扫荡记录在案的三件小尾巴（§6.1 / §6.2 / 索引自陈的文档债），一次清掉。

## 第一件：测试制品不再弄脏工作区（§6.1）

现状：e2e 套件每次运行都会重写已被 git 跟踪的截图与日志（`tests/m29-shots/*.png` ×5、`tests/e2e_cf.frames.log` 等），跑完测试 `git status` 必然是脏的，证据图与运行产物混为一体。

定案的政策（按此实施，不再另议）：
- 套件的**默认输出**改到 gitignored 的运行目录（如 `tests/out/`，加入 .gitignore）：截图、frames 日志等每次运行新写的都进那里；
- 已跟踪的 `tests/*-shots/` 证据图**冻结**为精选证据：套件只有在显式证据模式（如环境变量 `EVIDENCE=1` 或现有 M26_ONLY 式开关）下才写回这些目录，普通运行不许触碰；
- 验收硬指标：完整跑一遍全部套件（e2e_m19、e2e_m29、e2e_cf、vitest、插件套件）之后 `git status --porcelain` 为空（除本任务自身的预期改动外）。这一条要写进报告作为证据。
- AGENTS.md 补一行该政策。

## 第二件：模型选择器 mock e2e 覆盖（§6.2）

现状：模型选择器只有插件侧测试与生产探活覆盖，SPA 的 mock e2e 里没有它——UI 回归只能靠真人发现。

补 Playwright 覆盖（用现有 mock agent 的 models 数据）：
- 打开模型选择器 → 列表渲染（厂商分组/当前模型标记）；
- 切换到另一个模型 → 走完 model_changed 流程 → 页眉/选择器显示新当前模型；
- vision 标记（M31 加的白名单布尔）在列表中的呈现（如有 UI 呈现的话；没有就只断言数据不报错）；
- 切换后发一条消息，断言 mock 侧收到的模型上下文与选择一致（以 mock 可观测的为准，不许假断言）。

## 第三件：protocol/frames.md 补全

现状：frames.md 缺 M8 时期的若干帧组（M38 索引自陈）。做法：从代码两侧枚举全部帧类型（plugin/frames.py + relay 转发 + SPA 的发送/处理分支），与 frames.md 现有条目逐一对账，缺的补齐（帧名、方向、字段、序号/回放语义、错误码），过时的改对。产出一张「帧清单对账表」放报告里：总数、原有、新增、修正各多少。

## 约束

- 本任务原则上是 tests/docs/tools 改动；如发现必须改产品代码才能完成第二件的断言，先在报告里说明再动手，改动面最小化。
- CI 路径门控与触发规则不许动。
- 既有套件全绿并报数；收尾跑一次 tools/verify_release.py 确认线上与仓库仍一致（若本任务没动产品代码，线上构建号应与 M39 一致）。
- 报告 `docs/m40-report.md`：三件各自的证据与结果，含「全套件后 git status 为空」的实测记录。
